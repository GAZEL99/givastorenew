CARA DEPLOY ADMIN PANEL SEBAGAI SITUS TERPISAH (beda domain dari GivaStore)
=============================================================================

Kenapa dipisah: kalau digabung satu Vercel project sama storefront, admin
panel ikut numpang di domain yang sama (givastorenew.vercel.app/admin.html).
Dengan cara ini, admin panel jadi project & domain SENDIRI, terpisah total
dari situs utama - jadi walau ada masalah di storefront publik, admin panel
gak ikut kena, dan sebaliknya.

LANGKAH 1 - Bikin repo GitHub baru (JANGAN pakai repo givastorenew yang lama)
------------------------------------------------------------------------------
1. Buka github.com -> New repository -> kasih nama misal "givastore-admin"
   -> Private (WAJIB private, biar orang lain gak bisa lihat source code admin)
2. Di terminal Alpine kamu:

   mkdir ~/givastore-admin
   cd ~/givastore-admin
   git init
   git branch -M main
   git remote add origin https://github.com/USERNAME_KAMU/givastore-admin.git

3. Extract isi zip ini LANGSUNG ke folder ~/givastore-admin (bukan di dalam
   subfolder). Hasil akhirnya harus kayak gini:

   ~/givastore-admin/
     index.html
     sw-push.js
     manifest.json
     robots.txt
     package.json
     vercel.json
     api/send-push.js
     icons/icon-192.png
     icons/icon-512.png
     icons/icon-maskable-512.png

4. Commit & push:
   git add .
   git commit -m "Setup admin panel terpisah"
   git push -u origin main

LANGKAH 2 - Bikin project Vercel BARU (terpisah dari project givastorenew)
------------------------------------------------------------------------------
1. Buka vercel.com -> Add New... -> Project
2. Import repo "givastore-admin" (BUKAN givastorenew)
3. Biarkan default (Framework: Other), klik Deploy
4. Setelah selesai, kamu dapat domain baru, misal:
   givastore-admin.vercel.app
   (beda total dari givastorenew.vercel.app milik storefront)

LANGKAH 5 - Amankan lebih lanjut (opsional tapi disarankan)
------------------------------------------------------------------------------
- Data (Supabase project & tabel orders) TETAP SAMA seperti storefront - yang
  dipisah cuma tempat HOSTING/domain admin panelnya. Login admin tetap pakai
  Supabase Auth yang sudah ada di index.html (email+password), itu tetap jadi
  garis pertahanan utama - pastikan password akun admin kuat & jangan dibagi.
- Kalau mau makin aman, aktifkan "Vercel Authentication" / Password Protection
  di Settings project (fitur bawaan Vercel, kalau tersedia di paket kamu) -
  supaya sebelum sampai ke halaman login pun, orang luar udah diminta password.
